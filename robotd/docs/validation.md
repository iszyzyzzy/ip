# Rust 迁移验证记录

2026-10-21，在 Windows x64 上运行 Rust 服务端模拟模式，通过原有 Python protobuf 客户端访问，未连接机器人硬件。

## 软件验证

- Rust 核心测试 3 项：CDC COBS/CRC 与底盘报文向量、配置校验与 SQLite revision、旧版动作 JSON 与删除版本。
- gRPC 集成测试 7 项：旧数据库迁移和鉴权、运动/动作/配置持久化、PCM 任意分包与尾部、断流恢复、停止/取消/独占流、非法输入、模拟 GPT-SoVITS HTTP 分块转发。
- 独立网页网关测试 6 项：HTTP/WebSocket、鉴权、租约与 TTL、动作、后端失联与恢复后不重放。
- Rust fmt、Clippy（警告视为错误）和改动 Python 文件的 Ruff 检查通过。
- Linux ALSA 路径完成类型检查，并成功链接 Linux ARM64 发布版。ARM64 产物以 glibc 2.36 为基线，运行需 `libasound.so.2`，适用于 64 位 Raspberry Pi OS Bookworm 或相容环境。

## 内存采样

以下是 **Windows x64 优化发布版 + 模拟 PCM 后端** 的一次进程采样，不能当作树莓派或真实 ALSA 的测量结果。流为 32 kHz、单声道 PCM16，共 4 秒；发送速度快于播放速度。

| 指标 | 空闲 | 播放中 |
| --- | --- | --- |
| 工作集 | 8,196,096 B（7.82 MiB） | 9,089,024 B（8.67 MiB） |
| 私有提交内存 | 1,314,816 B（1.25 MiB） | 1,536,000 B（1.46 MiB） |

PCM 软件队列峰值为 160 ms（10,240 B），最终提交 128,000 帧，与输入一致。队列满后停止读取上游，未缓存整段语音。Windows 发布版文件为 6,281,216 B，ARM64 发布版约 5.1 MiB。

真实 I²S 出声、声卡协商缓冲、系统负载下的延迟，以及 H7、总线舵机和眼屏的联合运行仍需上机验证。首包到播放后端的计时不包含 TTS 生成与扬声器出声时间。
